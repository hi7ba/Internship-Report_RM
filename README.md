# SONATRACH Internship Report — Web Development & IT Infrastructure

## Overview

This repository contains my internship report completed during my second year of a Professional Bachelor's degree in Computer Science, specializing in Networks and Web Technologies.

The internship took place at **SONATRACH — Adrar Refinery (RA1D)**, within the Information Technology Department (DTI), from April 28 to June 5, 2024.

The report documents my experience in a professional IT environment, with a particular focus on developing a web application for managing employee room occupancy.

## Project: Employee Room Management Application

The main development task was to build a web application to help manage employee accommodation, room occupancy, and reservations.

### Key features

- Room occupancy tracking and identification of vacant rooms.
- Management of room assignments and reservations.
- Management of employees and temporary guests.
- Filtering and organization of room-related information.
- Detection of unavailable or out-of-service rooms.
- Administrative data management through Django Admin.
- Recurring occupancy period management to reduce repetitive data entry.

## Technologies and Tools

- **Python** — Programming language.
- **Django** — Web development framework.
- **SQLite3** — Relational database.
- **UML** — System modeling and design.
- **PlantText** — UML diagram creation.

## Internship Experience

Beyond application development, the internship provided exposure to the refinery's IT infrastructure, including:

- Computer networks and VLAN segmentation.
- Network cabling and connectivity testing.
- IP addressing and basic network troubleshooting.
- File sharing and access permissions.
- Server infrastructure and virtualization.
- Backup and recovery solutions.
